# dotOrcA — S00 Rust GUI arena
Provisional comparison branch, not the production application. Original Go/Fyne experiment remains in test/s00-foundation. No encoding, predictions or hardware probing.

Compare WinSafe 0.0.29, native-windows-gui 1.0.13 and GPUI Kit 0.11.0 on Windows x64 with identical worker and basic file-drop behavior. Round 1 is a startup/functionality screening build; native controls use their default theme until dark-theme implementation is qualified. Do not select a final winner before dark-theme, DPI, clean-host and performance validation. See docs/ARENA.md.
