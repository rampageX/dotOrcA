- CPU proxy for explicitly mapped different CPUs: use same fixture/encoder/preset/bitrate/tool build, geometric mean of public single/multi score ratios; reject ratios outside 0.5–2.0 and mismatched thread inventory. Conservative range uses 0.5 times lower index ratio and upper index ratio. This is a heuristic envelope, not a calibrated statistical interval or proof of encoding speed. No extrapolation for arbitrary real content, HDR, other bitrate or unmeasured resolution. Unknown hardware/tool/route returns unknown, never zero. GPU cross-model numerical transfer intentionally withheld until isolated and/or paired pipeline evidence exists; GPU map does not multiply FPS by engine count.
