Base: main 4bcbd10d71a15d22804e999fca22d795a284e2d2. No GUI, capacity, route selection, production pipeline or self-learning.

- Imported both S02 reports by reconstructing all text chunks, matching raw UTF-8 SHA256 exactly to S02.md, parsing full JSON, checking the 288 unique cases per report, 132 successful cases and 156 skips each. Cross-checked fixture file and decoded hashes, output codec/depth/size/frame count/duration/FPS/bitrate/quality. Official data/s02-physical-v1.json stores 264 measured observations in data/official/, with source hashes, machine and sanitized argv (input/output placeholders), driver/tool fingerprints, decode baseline, actual quality/bitrate. Raw reports, paths, logs, device IDs not committed. Dataset source commit 81c3c0b43ab628ab06963c73f17b3c23759ddb96. The 312 skipped rows are not numerical observations.
- Versioned public hardware-map-v1 includes four CPU models (NanoReview Geekbench 6 single/multi aggregate, source URL and retrieval date) and five NVIDIA products (vendor matrix NVENC generation, engine count and mobile distinction). These are external reference indices/specifications, not dotOrcA measurements. No substring model matching, no CUDA/game performance scaling. Radeon model/engine and unknown adapters remain unmapped. S01 capability probes are mandatory for GPU predictions and do not prove specific adapter attribution.
- Same exact S02 reference fixture, route, preset, bitrate, bit depth, hardware inventory/driver and tool hashes: measured wall-clock reference, limited single-run confidence. Estimated seconds for arbitrary frame count are only a linear reference projection; no measured interval, sustained throughput or production ETA. Separate decode-only timing is evidence, not subtracted. Exact observed values and inferred time are distinct fields.
- CPU proxy for explicitly mapped different CPUs: use same fixture/encoder/preset/bitrate/tool build, geometric mean of public single/multi score ratios; reject ratios outside 0.5–2.0 and mismatched thread inventory. Conservative range uses 0.5 times lower index ratio and upper index ratio. This is a heuristic envelope, not a calibrated statistical interval or proof of encoding speed. No extrapolation for arbitrary real content, HDR, other bitrate or unmeasured resolution. Unknown hardware/tool/route returns unknown, never zero. GPU pipeline cross-model numerical transfer intentionally withheld until isolated and/or paired pipeline evidence exists; GPU map does not multiply FPS by engine count.
- Separate external NVIDIA Video Codec SDK 13.1 reference, data/official/nvenc-sdk13.1-v1.json: vendor measurements for reference devices at 1080p 8-bit 4:2:0 VBR HQ, single NVENC engine, P1/P3/P5/P7. Exact architecture AND engine generation required, desktop only. Even presets use geometric interpolation, not vendor measurement. Clock scaling requires an explicitly supplied observed video-engine MHz, not advertised graphics clock; ratio restricted to 0.5–1.5. Missing clock returns vendor anchor only, T600 (6th generation) cannot inherit RTX 8000 (7th generation), and uncalibrated mobile devices are excluded. No engine-count multiplier, no linkage to S02 wall-clock data, no production ETA. Vendor-derived estimates are low-confidence hypotheses, not dotOrcA measurements.
- CPU leave-one-machine-out validation (144 CPU observations; each target machine excluded from reference data; public indices unchanged): median absolute relative error across six encoder/machine groups 3.66–8.20%, p90 11.15–14.92%; 139/144 inside the heuristic envelope, 0/144 below its lower FPS endpoint. Calculated from existing S02 data, not independent new measurements and not calibrated probability coverage. CLI --holdout and CI artifact holdout.json reproduce the calculation.
- Bundled official dataset read-only, explicitly supplied local dataset read-only and independent; validates origin/schema and duplicate report identities. S07 owns updates/learning. No runtime scripts or network requests.
- Production ETA and isolated GPU FPS intentionally null. Real source content, decode route, bitrate, long clips, sustained thermals, cross-GPU calibration and independent validation need more evidence. Do not treat these limits as passed requirements. S04/S05 may consume explicit uncertainty; S05 must not choose software based on unknown or unvalidated proxy.
