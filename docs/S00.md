## Proposed module boundaries (not implemented except contracts and probes)
- root / internal/contract: shared typed requests, media facts, decisions, estimates, measured records.
- internal/probe + internal/process: media/hardware tools, process lifecycle; S01.
- cmd/benchmark + internal/benchmark: separate entry point with shared process/probe; S02.
- internal/predict: CPU/GPU models, uncertainty, data provenance; S03.
- internal/budget: final container/audio/video budget; S04.
- internal/decision: policy and explainable route selection; S05.
- internal/pipeline: staging, cancellation, verification, fallback; S06.
- internal/dataset: independent official and local stores; S07.
- gui/ separate Go module: Fyne-only adapter and future presentation; S08. No production GUI in S00.
- Core packages must never import GUI. GUI integration later via root public facade; don't bypass internal package visibility.

## Proposed data and portability decisions
Use int64 bytes internally, rational FPS, explicit unknown measurements and versioned schemas. UI unit (MB/MiB) and whether batch limit is per-file or combined remain user decisions. Keep encoder choice, format, color metadata, estimated and measured performance distinct. Store source path separately from temp/output paths. Keep portable configuration and data beside executable (not current directory); fail with a clear message if not writable. Proposed layout: dotOrcA.exe, tools/, data/official/, data/local/, config/, logs/, work/. Do not rely on OS registry for project state. Fyne preferences may use OS storage by default; production must avoid or override this and test side effects. No bundled encoder license decision yet.

## Risks
Windows graphics driver/OpenGL support (including remote sessions/VMs) is the main GUI qualification risk; if failing target use cases, compare native Win32 GUI toolkit rather than silently changing architecture. Fyne default glyph coverage and native appearance need testing; no unsupported Windows 7 promise. CI cannot substitute for interactive drag/DPI tests. S00 prototype build not a production GUI or codec test.
