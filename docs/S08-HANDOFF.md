# S08 接力卡 · 暗黑 GUI、拖放及批量任务管理

从包含 PR #9 和本卡的 main 开始。按 AGENTS.md 读取章程、总任务卡、架构与 S00–S07 验收记录。仅开发 S08。

- 基于已固定的 CUI v1.5.0 与 CPU 软件渲染，提供单窗口暗黑界面、文件拖放、批量队列及任务操作。主界面仅暴露目标容量、输出 codec、最大分辨率及任务操作。界面明确标注容量单位及批量容量口径。
- 通过公开 Rust 核心入口提交任务，复用 S01–S07 探测、预算、路线、发布及本机学习。GUI 读取最新不可变快照，显示进度、路线、已知的预计值与最终结果。保留取消、失败及回退原因，未知 ETA 保持未知。
- 首屏前避免硬件探测、网络和数据扫描。后台任务通过有界状态更新与界面交互，保持队列响应。便携路径以 EXE 目录为根，显式提示不可写、队列失败及输出冲突。
- 自动回归覆盖拖放和特殊路径、批量结果、取消、失败、界面响应与 Rust/C 边界。记录真实 Windows 双屏混合 DPI 与缺 CJK 字体的验证状态。干净主机验收、生产 ETA 独立校准与 RTX 4080/T600 生产硬编实测留在 S09。
