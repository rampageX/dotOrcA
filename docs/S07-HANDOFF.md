# S07 接力卡 · 本机自学习与训练数据库更新

从包含 PR #8 和本卡的 main 开始。先读 AGENTS.md、章程、总任务卡、架构及 S00–S06 验收记录。S07 范围如下。

- 仅接收 S06 已校验并成功发布的生产观测，记录实际路径的耗时、最终容量、重试及回退，并按设备、驱动、工具、编码路线及媒体特征区分。失败和取消不进入学习样本。记录保留证据来源，不上传遥测或源文件路径。
- 本机数据、官方版本及配置各用独立存储。官方更新验证版本、完整性及结构，事务切换。拒绝无效或不兼容的包，更新中断时保留可用版本，迁移兼容已有文件。
- 本机观测可用于同类任务的保守参考。样本不足、指纹不符或缺独立校准时保持未知。不得把未经校准的 ETA 或单独的容量观测用于 S05 主动软编门禁。独立校准与 RTX 4080/T600 生产硬编实机验收在 S09。
- 自动回归覆盖更新失败与并发、本机数据隔离、坏数据拒绝、历史版本读取及样本不足。按仓库纪律一次逻辑提交，并跑完整回归。
