# dotOrcA 项目章程 V1.2（v1.1.0）

## 定位
独立自动视频压缩软件，不依赖 Film Grain Studio，不继承其历史代码或架构。用户无需视频编码知识。在不超过指定文件容量前提下尽可能保留画质，轻量、快速、可靠，不引入无法充分验证的智能化。

## 技术选型
Rust + CUI v1.5.0（CPU 软件渲染，完整暗黑），Windows x64；便携单 EXE，外置编码器。核心引擎与 GUI 独立，核心纯 Rust，GUI 允许薄 C FFI，GitHub Actions 自动构建测试。运行时不依赖 PowerShell、BAT、Python、.NET、WebView2。外部程序通过 Rust std::process::Command 直接传参，不走 Shell。此处取代 V1.0 的 Go/Fyne 选型，其余目标不变。

## UI
暗黑主窗口、独立非模态只读详情窗口、拖放、批量任务、简体中文和英文。主要设置仅目标容量、目标视频编码格式、最大输出分辨率；其余自动决策。显示实际路线、进度和最终压缩结果。首屏优先，后台复杂性不转嫁用户。

## 压缩策略
最终容量硬约束，在约束内追求最佳画质。支持固定容量或按每个原文件字节数的百分比（互斥，百分比表示目标保留比例）。源文件已不超过上限时直接跳过，不转码、不复制、不因指定编码或最大边而强制重编码。分析源视频时长、分辨率、帧率、格式及 HDR，计算音视频码率预算并选择编码参数。不超过 600 秒的源视频只按最大边等比缩放（上限内保留原始尺寸），启用 FastStart；超过 600 秒启用 BPP 自适应分辨率，关闭 FastStart。实际输出帧率包含 BWDIF 2×，不自动降帧。输出命名统一为原文件主名_容量或百分比_编码格式_设定最大边.MP4（例如 Movie_100M_HEVC_1920.MP4 或 Movie_50%_HEVC_1920.MP4）；目标已存在则跳过并显示原因，不覆盖、不自动编号。避免无意义放大、升帧及重复编码。编码后验证真实容量，必要时自动调整重编码。保证音画同步和色彩信息；尽可能保留 HDR，不允许无提示转 SDR。生产仅硬编；失败直接报告，不自动软编。质量控制采用 FFmpeg 编码器自身机制。

## 已取消路线
v1.1.0 正式取消 Benchmark、性能预测、训练数据库、官方数据更新及本机学习，不再重新研究。S02/S03/S07 文档仅作历史记录；不增加试编码或媒体扫描。

## 工程纪律
从第一天维护 AGENTS.md、自动测试和发布规范。重点路径 Unicode/特殊字符、参数传递、大文件/超长视频、磁盘空间、任务取消/子进程残留、临时清理、同步、失败回退、配置兼容、UI 阻塞、重复硬件检测。强制回归文件名：小K 的鹅腿坟场 & (黑洞) ^ % !.avi。关键决策有日志、测试依据、可解释。每阶段验收并更新总任务卡后再进入下一阶段；不赶进度，不提前堆功能。
