# S05 接力卡 · 软硬编码决策引擎

从包含 PR #6 及本卡的 main 开始；按 AGENTS.md 读取章程、任务卡与 S01–S04 验收记录。仅开发 S05。

- 输入使用 S01 的源信息、实际能力与设备/驱动/工具指纹，S04 的单文件预算、指定 codec、尺寸、时间戳、位深与颜色保留要求。预算失败应返回原原因。小尺寸能力探针仍需和实际请求适配。
- 默认硬编。主动软编须同时具备可信的全任务 ETA ≤180 秒、速度 ≥1×、可信画质或压缩效率收益。缺失任一证据应记录具体原因。S03 参考预测、短窗点估计及 S02 合成图 SSIM 均不足以单独放行。
- 将主动软编和硬件不可用/失败时的回退分开表达；禁止静默改格式、降位深或 HDR 转 SDR。输出候选路线、原因码、证据来源和未知项。
- 自动验收覆盖准入三条件的等号边界、任一失败或未知、无可用硬件、输入约束冲突。用可控测试输入覆盖未来 ETA；现阶段生产 ETA 仍未知。遵守一次逻辑提交与完整阶段回归纪律。
- S06 负责真实编码、超限重试、最终文件实测门禁与事务发布；S09 负责独立校准。本阶段不重复 S02/S03 跑分。
