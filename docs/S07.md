# S07 本机生产观测与官方训练库

- 正常生产入口 `pipeline::encode_and_learn` 复用 S06。只有封装校验、容量检查及目标发布全部成功才写入。记录最终路线、完整任务耗时、最终成功编码到封装关闭的耗时、最终字节数、超限重试次数、被拒的预检与执行路线、回退原因和 S06 证据来源。工具指纹使用 FFmpeg 与 FFprobe 的 SHA-256，生产前后校验一致。学习写入错误由 `TrackedPublication.learning` 独立返回，已发布的成品仍有效。
- 便携根目录下，`data/local/production-v1.json` 保存最近 4096 条生产观测，`data/official/active.json` 保存当前官方数据包，`config/` 仍由调用方管理。样本按 CPU、逻辑线程、GPU 实例与驱动、工具哈希、实际编码器、目标设置及可用的源视频和音频特征匹配。样本不包含路径、原始媒体标签、命令行或诊断文本。S07 不发起遥测或网络请求。
- `Store::install_official` 接收调用方下载的 UTF-8 JSON 包和来自可信发行元数据的包 SHA-256。格式为 `{"schema":1,"version":2,"dataset":"<S03 官方训练数据 JSON 文本>"}`，外部摘要为整个包的 64 位小写十六进制 SHA-256。包版本须大于现用版本。官方生产参考资产沿用 S03 结构校验，硬件映射和 NVENC 厂商参考表随程序版本提供。写入锁内复查版本，经同目录暂存、文件同步及原子替换后生效，读者只读已提交快照。中断留下的暂存文件由后续更新回收。
- 内置 S03 数据是官方库版本 1。已有 S03 本机基准文件仍用 `Database::with_local` 显式读取，原地保留。生产记录采用独立格式，旧基准不会被当成生产观测。
- `Store::history` 在完整条件精确匹配且至少三条样本时返回历史最慢耗时和最大容量。缺样本或指纹不完整时返回未知。历史统计不进入 S05 的主动软编门禁。生产 ETA 仍需 S09 独立校准，RTX 4080/T600 实机生产硬编也在 S09 验收。
